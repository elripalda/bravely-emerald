# Performance

Measured on the Steam Deck. Source: [results/deck-visual-phase1-perf.txt](results/deck-visual-phase1-perf.txt).

Before the post effects were added, a 200 s scripted run in the 60 FPS mode presented a frame every
16.67 ms (p99 17.62 ms, 1.2 percent of frames over 17.5 ms).

Frame timing with the effects on has not been measured yet.

The telemetry that records frame times (`perf_frames.csv`) is described in [DEBUGGING.md](DEBUGGING.md).
